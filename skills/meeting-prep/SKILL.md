# Meeting prep

Before-the-call pack so the user walks in ready. Facts only; gaps labeled.

## When to use

- User has an upcoming meeting and asks to prep
- User names a calendar event, invite, or person and wants a one-pager
- Complements Meeting → Actions (that skill is for *after* the meeting)

## Required inputs and access

**Inputs (required)**
- Which meeting: calendar link, event name + time, or attendee list + topic

**Useful extras**
- Prior notes, CRM account, or last email thread
- Goal for the meeting (decide / sell / sync / interview)

**Access**
- Calendar read for attendees and time
- Email / docs / Notion only if needed to find last notes the user pointed at
- Do not join the call or message attendees unless asked and approved

If the meeting cannot be identified, stop and ask. Do not invent an agenda from a blank calendar.

## Steps

1. Identify the meeting: time, title, attendees, location/link.
2. Gather last touchpoints: prior notes, open actions, recent email — only from real sources.
3. List open actions with owners if known; mark unknowns.
4. Draft 5 bullets the user may want to say (aligned to their stated goal).
5. Draft 3–5 questions to ask.
6. Flag risks: missing decision-maker, expired deadline, conflicting notes.
7. Do not reschedule, send prep email, or create calendar holds without approval.

## How to validate

- Attendees and time match the calendar or invite
- No fabricated prior commitments or quotes
- Open actions cite a source or are marked "unverified"
- Calendar was not modified

## Always ask for approval when

- Emailing or messaging attendees
- Creating, moving, or canceling calendar events
- Writing notes into a shared doc or CRM
- Booking follow-ups
